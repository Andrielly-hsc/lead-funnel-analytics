## Description

Turn rules into metrics per table and dimension.

## Steps

1. Completeness: % non-null of required fields
2. Uniqueness: % rows unique on business key
3. Validity: % values in domain/range
4. Consistency: cross-field/cross-table rules (opportunity date ≥ lead date)
5. Accuracy: compare with `_ground_truth.json` (only possible because data is synthetic)
6. Timeliness: lag between event and `_loaded_at`
7. Output `reports/quality/scorecard.md` + chart

## Acceptance criteria

- [ ] Scorecard regenerated by one command
- [ ] Each metric has a defined threshold and pass/fail

## Deliverables

- `src/lead_funnel/quality/scorecard.py`
- `reports/quality/scorecard.md`

## Why this matters (best practice)

These six dimensions come from DAMA-DMBOK and ISO 8000 — standard vocabulary in data governance roles.
